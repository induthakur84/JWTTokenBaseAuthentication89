Classroom Explanation: How JWT Works in Angular + .NET

Explain these 4 steps to your students

1

User Authenticates

Student fills in username & password on Login page. Angular sends POST /api/User/Login over HTTPS.

2

.NET Issues Signed JWT

The backend verifies password hash using BCrypt. It builds claims (Role, Username) and signs with SecretKey.

3

Stored & Intercepted

Angular stores token in localStorage. The jwtInterceptor attaches Authorization: Bearer <token> to every request.

4

Role Authorization

ASP.NET Core verifies signature and checks [Authorize(Roles = "Admin")]. If role matches, it returns 200 OK; otherwise 403 Forbidden.
